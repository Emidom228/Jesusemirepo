# **Máquina de Corte Láser: Funcionamiento**
*8 de Septiembre*

### **Pasos para utilizar la máquina**
| Imagen | Pasos |
|--------|-------------|
| ![Láser](../../img/laser1.jpeg)" | 1. Encender el interrumptor con la mano |
| ![Láser1](../../img/laser.jpeg)" | 2. Verificar que no aparezca ningun aviso o advertencia. |
| ![Láser2](../../img/laser2.jpeg)" | 3. Encender un switch que se encuentra del lado derecho de la máquina, después el boton de paro de emergencia y por último, insertar la llave proprocionada por el profesor y girarla.  Con esto la máquina ya esta lista para trabajar |
| ![Láser3](../../img/laser3.jpeg) |4. Con las flechas definir el origen, esto asegura donde va a empezar la máquina el corte. |
| ![Láser4](../../img/laser4.jpeg) | 5. Colocar el material, y dejar una distancia como de 1cm aproximadamente. |
